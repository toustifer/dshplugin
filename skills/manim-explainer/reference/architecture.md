# 架构设计与运行时数据流

深入理解插件底层的进程边界与数据流转，能够帮助 Agent 在复杂交互中准确定位职责边界。

---

## 1. 进程拓扑结构

系统运行在四个独立的进程空间：

```text
┌─────────────────────────────────────────────────────────────┐
│                    DSH Web 前端 (浏览器)                     │
│  ┌─────────────────────────┐   ┌─────────────────────────┐  │
│  │   dsh-manim-gallery     │   │     dsh-media-view      │  │
│  │   (右侧栏动画库 Tab)     │   │   (publish_file 专用卡片)│  │
│  └─────────────────────────┘   └─────────────────────────┘  │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTP / WebSocket RPC
┌──────────────────────────────▼──────────────────────────────┐
│                    DSH 宿主服务 (Node.js)                    │
│  - fs-sandbox 驱动器盘符基准                                 │
│  - /api/file 静态文件安全服务 (Cookie/Token 鉴权)            │
│  - LLM 上下文注入与调度引擎                                 │
└──────────────────┬───────────────────────┬──────────────────┘
                   │ stdio JSON-RPC        │ stdio JSON-RPC
┌──────────────────▼──────────┐ ┌──────────▼──────────────────┐
│      manim-mcp (Python)     │ │     media-mcp (Python)      │
│  - 模板编译器               │ │  - MIME 嗅探器              │
│  - Manim 执行引擎           │ │  - PDF 3页光栅化转换器       │
│  - diagnostics 错误解析器   │ │  - 安全边界与同源引用生成器 │
└─────────────────────────────┘ └─────────────────────────────┘
```

## 2. 动画制作全链路数据流

1. **意图触发**：模型在回答深层数学/算法/时序问题时，`manim-explainer` skill 生效。
2. **工具调用**：模型调用 `mcp__manim__*`（如 `equation` 或 `render`）。
3. **渲染产出**：
   - `manim-mcp` 将源码编译并调用 `python -m manim` 渲染生成 MP4 视频。
   - `ffmpeg` 后处理提取首帧为海报 PNG，并转录为高保真动图 GIF。
   - 生成结构化信封：包含 `previewMarkdown`（去盘符的同源引用）与真实文件路径。
4. **正文呈现**：
   - 模型接收到工具返回，提取非空 `previewMarkdown` 原样贴进回答 Markdown。
   - 浏览器解析 `![anim](/myprogram/...)`，向 `/api/file` 请求字节，在正文中内嵌动态播放。
5. **持久化与回看**：
   - 渲染元数据存入 `renders/index.json`。
   - 用户点击右上角「动画库」图标，`dsh-manim-gallery` 从右侧滑出，读取索引并提供全屏/列表视频回看。
